# Design system: Scryglass (Miller lock)

## Visual theme
Credible editorial magazine × Kyle Anthony Miller tactical industrial.
Warm sand / warm charcoal. Safety orange + field olive. Dense micro-labels under airy hierarchy.
Not hospital, not empty Notion, not financial-dashboard card grids.

## Typography
- Display: Unbounded 600/700 (wide/heavy)
- UI: IBM Plex Sans 400/500/600
- Mono: IBM Plex Mono — tables and numbers only

## Theme
System / Light / Dark. System default. Equal citizens.

## Patterns
- Orange status pills (ALL CAPS)
- Tiny ALL-CAPS key:value micro-logs
- Corner aperture marks on hero only
- Borderless whitespace tables
- Ticker scoreboards (flat rows, mono metrics)
- Blog-first home

## Motion
Expressive: 150–400ms fades, count-ins, chart draw-ins.
