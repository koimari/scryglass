# Public-surface claim and calculation ledger — 2026-07-27

## Audit decision

**Do not treat the current public surface as scientifically release-ready.** The article’s central void-grubs estimands and the sandbox’s probability-withholding copy are mostly sound, but seven cross-surface defects can produce or label materially different quantities as if they were the same:

1. Historical map pick columns can be interpreted as role order, corrupting role-aware Draft Score.
2. The sandbox declares its terminal composition model failed a chronological probability gate and withholds probability, while the normal Draft WR API still publishes composition probabilities without exposing a distinct passing gate/model.
3. The public pack is older than the source contracts now expected by the app: current-membership registry, player identifiability, canonical series, full map population, and detail provenance are missing.
4. Direct team/player pages bypass the ladder’s membership fail-closed gate and call historical affiliations “current-tournament” membership.
5. The team ladder is a hierarchical Bradley–Terry model but is repeatedly called “Dual Elo”; its Evidence label also applies the sequential benchmark’s sigma floor to the hierarchical model.
6. A favorite hit rate is called “accuracy,” while proper scores and calibration are not shown; the kills “prior” uses the complete pack year, including later maps.
7. Reproduction links expose a stale, over-broad manifest while omitting the full-composition artifact required to reproduce Draft Score.

This is a source-and-artifact audit, not a styling review. Line references describe the concurrent filesystem snapshot read immediately before this ledger was written. No application source was changed.

## Scope, method, and classifications

The audit covered all 17 public entry points under `apps/lol-atlas/src/app/**/{page,route}.ts*`, every component imported by those pages, and their direct calculation/data dependencies in `src/lib`. The closure included:

- Components: `ArticleContestCharts`, `ArticleShell`, `BrowseMaps`, `DraftSandbox`, `DraftWrPanel`, `EloLadders`, `HeadToHead`, `MatchLoader`, `MatchScoreboard`, `ModelChecklist`, `PdfEmbed`, `PlayerEloDetail`, and `TeamEloDetail`.
- Direct libraries: `articles`, `draftComposition`, `draftLineup`, `draftRules`, `draftScore`, `duck`, `format`, `formulaHtml`, `pack`, `pstar`, `series`, and `serverPack`.
- Cross-surface chrome: `layout.tsx` and `SiteChrome.tsx`.
- Dormant live-read code was inspected because `/live` is a public route and live placeholder safety was an explicit audit requirement.
- Producer/data provenance was traced into `lol_kills/ratings/*`, `lol_kills/export/*`, `lol_kills/research/grubs_action_graph.py`, the checked-in manifest, the current composition runtime, and the mutable public pack pointer.

Statuses:

- **Verified** — the public wording and behavior match the traced code/data/model contract.
- **False/misleading** — the wording is false, conflates estimands, or a fallback can emit a different quantity under the same label.
- **Unverified** — the code or public artifact lacks enough provenance/schema evidence to support the claim.
- **Non-scientific UI** — a descriptive/editorial/interface value that should not be presented as model validation.

Severity:

- **Blocker** — can materially reverse/corrupt a public conclusion or violate a core safety/provenance contract.
- **Critical** — materially false public semantics or unreproducible model/data behavior.
- **High** — important scientific/data-integrity defect.
- **Medium** — bounded misleading wording, clock, or fail-closed defect.
- **Low/Info** — limited public impact or a verified guard worth retaining.

- Independently, the current sandbox response hard-codes `probability_status: "withheld_failed_chronological_gate"` and reports 2,477 final-test maps. No public artifact establishes that the normal Draft WR probability is a different model/version with a passing gate.
- The mutable grubs artifact reports a contest bar of `58.9%`; at a `50%` fight-win chance, leave leads by `2.08pp`. The sister OE leave-mix break-even is `24.47%` on 7,846 trailing maps.

## Minimum release-gate regression suite

- **Draft provenance gate:** participant-role versus draft-order fixtures; null roles fail closed; patch canonicalization table; unknown/duplicate/unsupported API cases; missing runtime returns typed unavailable.
- **Estimand-label gate:** render distinct raw composition, contextual pre-match, sandbox policy utility, side baseline, probability-gate status, and proper model IDs.
- **Pack identity gate:** equal or explicitly reconciled game-ID populations across maps, records, rating input, and explorer; immutable page/API/download pack IDs agree.
- **Membership gate:** current registry authority/review clock required on list and direct profile routes; legacy artifact fields fail closed.
- **Player-identifiability gate:** absent metadata is unknown, never separately identified; shared outcome cohorts cannot receive an individual Evidence claim.
